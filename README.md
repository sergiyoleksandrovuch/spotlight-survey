# Spotlight City — опитування

Сайт-опитування (статичний, без збірки). Відповіді йдуть у Google Таблицю «Spotlight City — відповіді опитування» через Apps Script «Spotlight City — приймач опитування».

- Адреса приймача — у `config.js`.
- Мітка каналу: додайте `?src=instagram` / `?src=telegram` / `?src=street` до посилання.
- Читабельні вихідні файли та інструкція — у локальній папці `D:\\Навчання\\Конкурс\\Опитування_сайт`. Завантаження нових файлів сюди автоматично оновлює сайт на Vercel.
